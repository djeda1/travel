# VOYAGE — 3D-сайт туристического агентства

Не обычный лендинг, а путешествие: скролл управляет полётом камеры по 3D-миру.

1. **Главный экран.** Большой заголовок над морем облаков на рассвете.
2. **Скролл вниз.** Камера ныряет сквозь облака к **Мальдивам**, облетает остров, а вокруг в 3D появляются панели: «О направлении», «Впечатления» и «Пакеты».
3. Дальше камера поднимается над облаками и летит в **Египет** (пирамиды Гизы, Сфинкс, оазис), затем в **Швейцарские Альпы** (горы, озеро, шале).
4. **Финал.** Взлёт навстречу закату и форма заявки.

## Запуск

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # сборка в dist/ (статические файлы, подходят для любого хостинга)
```

## Где что менять

| Что | Файл |
| --- | --- |
| Тексты, цены, пакеты, контакты | `src/data.js` |
| Маршрут камеры и тайминг скролла | `src/journey.js` (`STATIONS`, `TIMELINE`) |
| 3D-панели вокруг локаций | `src/panels.js` |
| Сцены локаций | `src/world/tropical.js`, `desert.js`, `alps.js` |
| Небо, облака, освещение | `src/world/atmosphere.js` |
| Стили | `src/style.css` |
| Отправка заявок (CRM, Telegram, почта) | `bindForm` в `src/ui.js` |

## Технологии

- **Three.js.** Одна постоянная WebGL-сцена; все три локации процедурные, без внешних моделей.
- **CSS3DRenderer.** Инфо-панели — настоящий HTML в 3D-пространстве: текст чёткий, кнопки кликабельны.
- **Скролл.** Нативный, со сглаживанием. Возле каждой панели камера притормаживает, чтобы её было удобно читать.
- Адаптивная вёрстка для телефонов и десктопа. Учитывается `prefers-reduced-motion`.
